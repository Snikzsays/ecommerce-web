Manual Extraction Instructions:

  1. Open your FigJam design in a new tab
  2. Right-click on each image you want to use
  3. Select "Copy" or "Export" from the context menu
  4. Save images to your computer with descriptive names like:
    • tea-category-banner.jpg
    • assam-tea-product.png
    • coffee-category-icon.svg
